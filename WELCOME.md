## ❓ Common Questions

**Q: Do I need to code to update the website?**
A: No! Edit `lib/content.ts` and you're done.

**Q: How do I add images?**
A: Place in `public/` folder and reference them in components.

**Q: How do I change the colors?**
A: Edit CSS variables in `app/globals.css`.

**Q: Can I add more pages?**
A: Yes! Create `app/your-page/page.tsx` and update navigation.

**Q: How do I go live?**
A: Follow [LAUNCH_CHECKLIST.md](./LAUNCH_CHECKLIST.md).

**Q: What if I break something?**
A: Run `rm -rf .next && npm run build` to reset.
